# Financial & Economic Analytics Dashboards

A collection of Power BI projects that translate economic, financial and business datasets into structured dashboards and presentation-ready reports.

## Purpose

This repository demonstrates dashboard design, data organization and analytical communication in Power BI. Each project pairs an editable Power BI file with a PDF export so that the output can be reviewed without Power BI Desktop.

## Dashboard Portfolio

| Project | Analytical focus | Files |
|---|---|---|
| Peru Balance of Payments | External-sector flows, account composition and macroeconomic context | [Power BI](./Balanza%20de%20Pagos%20Peru%202024.pbix) · [PDF](./Balanza%20de%20Pagos%20Peru%202024%20Report.pdf) |

## Capabilities Demonstrated

- Data cleaning and transformation in Power Query
- Data-model organization
- KPI and comparative visual design
- Economic and market-structure interpretation
- Dashboard layout and information hierarchy
- Export of analytical dashboards into shareable reports

## How to Review the Work

- Open the PDF files for a direct view of each dashboard.
- Download the PBIX files to inspect queries, relationships, measures and visual configuration in Power BI Desktop.

GitHub does not render PBIX files in the browser, so the PDF exports serve as the public preview layer.

## Limitations

The projects were developed at different stages of the author's learning process and may use different design conventions or data vintages. Source definitions and refresh procedures should be reviewed before reusing a dashboard for current analysis.
